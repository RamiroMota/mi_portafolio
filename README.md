# Ramiro Mota — Portafolio Profesional 🚀

Este es mi portafolio personal, diseñado para destacar mis habilidades como **Desarrollador Full-Stack y Especialista en UI**. Construido con tecnologías de vanguardia para ofrecer una experiencia de usuario fluida, interactiva y de alto rendimiento.

## ✨ Características Principales

- **Arquitectura Basada en Slides**: Navegación fluida a través de secciones que funcionan como diapositivas de pantalla completa.
- **Diseño Premium & Glassmorphism**: Estética moderna con efectos de desenfoque, gradientes complejos y texturas de ruido.
- **Avatar 3D & Tech Stack Dinámico**: Sección de inicio con un avatar personalizado rodeado de iconos tecnológicos con animaciones orbitales y de flotación.
- **Totalmente Responsivo**: Optimizado para una experiencia perfecta en dispositivos móviles, tablets y escritorio.
- **Rendimiento de Élite**: Desarrollado con Astro 6 para una carga ultrarrápida y mínima hidratación de JavaScript.

## 🛠️ Stack Tecnológico

- **Framework**: [Astro 6.x](https://astro.build/) (Integración con React)
- **Librería UI**: [React 19](https://reactjs.org/)
- **Estilos**: [Tailwind CSS v4](https://tailwindcss.com/) (Vía `@tailwindcss/vite`)
- **Animaciones**: [Framer Motion](https://www.framer.com/motion/)
- **Tipografía**: Noto Sans (Títulos) & Quicksand (Cuerpo)
- **Iconos**: React Icons & DevIcons

## 📂 Estructura del Proyecto

```text
/
├── public/             # Archivos estáticos (imágenes, favicon)
├── src/
│   ├── components/
│   │   ├── atoms/      # Componentes básicos (botones, textos, iconos)
│   │   ├── molecules/  # Componentes compuestos (tarjetas, dots de nav)
│   │   └── organisms/  # Secciones completas (Hero, About, Projects, etc.)
│   ├── data/           # Información de proyectos, tech stack y redes sociales
│   ├── layouts/        # Plantilla base de la aplicación
│   ├── pages/          # Rutas (index.astro como entrada principal)
│   ├── styles/         # CSS global y configuración de Tailwind v4
│   └── types/          # Definiciones de TypeScript
└── package.json
```

## 🚀 Comandos Rápidos

Desde la terminal en la raíz del proyecto:

| Comando | Acción |
| :--- | :--- |
| `npm install` | Instala las dependencias necesarias |
| `npm run dev` | Inicia el servidor de desarrollo en `localhost:4321` |
| `npm run build` | Genera el sitio optimizado para producción en `./dist/` |
| `npm run preview` | Previsualiza la versión de producción localmente |
| `npm run astro -- --help` | Muestra la ayuda de la CLI de Astro |
